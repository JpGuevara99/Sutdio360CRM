# Documentación de Studio360 CRM

Esta carpeta es el lugar de la documentación de la app: **qué hace**, **cómo se usa** y **cómo está protegida**.

No es un manual de programación. El código vive en `src/`. Aquí se explica el producto para personas.

## Para quién es cada documento

| Documento | Para quién | Estado |
| --- | --- | --- |
| [Seguridad](./seguridad.md) | Cliente y dueños de la empresa | Listo |
| [Cómo documentar](./como-documentar.md) | Quien mantiene esta carpeta | Listo |
| Dashboard | Equipo que usa la app | Pendiente |
| Proyectos (Kanban, cierre, seguimientos) | Equipo | Pendiente |
| Clientes (alta, ficha, combinar) | Equipo | Pendiente |
| Cotizador (crear, clonar, PDF, Drive) | Equipo | Pendiente |
| Materiales | Equipo | Pendiente |
| Nuevo lead / proyecto | Equipo | Pendiente |
| Papelera de reciclaje | Equipo | Pendiente |
| Google Calendar, Drive y Tasks | Equipo y quien configura | Pendiente |
| Arranque y despliegue | Quien instala o publica | El [README](../README.md) de la raíz cubre lo técnico; falta una versión más simple |

## Cómo se lee esta carpeta

1. El cliente o un socio: empiezan por [seguridad](./seguridad.md).
2. El equipo comercial: cuando existan, los documentos por área (Proyectos, Clientes, Cotizador…).
3. Quien configura Firebase o Google: el README de la raíz, más adelante un documento de integraciones.

Si un documento está en **Pendiente**, todavía no se escribió. Eso no significa que la función no exista: significa que aún no está explicada aquí.
