# Brand assets (dejar logos aquí)

Copia aquí el archivo original del logo (PNG/SVG preferible) **sin subirlo al chat**.

## Archivo esperado

- Nombre sugerido: `logo-source.png` (o `.svg`)
- Ideal: fondo transparente, símbolo rojo + tipografía negra

Cuando lo dejes en esta carpeta, avísame en el chat y lo proceso a:

- `public/brand/studio360-logo.png` → modo claro / PDF
- `public/brand/studio360-logo-dark.png` → modo oscuro (tinta negra → blanca)

## Nota

Subir el logo por el chat a veces aplasta el fondo a negro y las letras negras dejan de verse. Leer el archivo desde disco evita ese problema.
